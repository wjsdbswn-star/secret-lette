안내 · 실험판의 보안 한계

단톡방에서 별도 암호키를 만들거나 입력할 필요는 없습니다. 안전을 위해 내부에서는 자동으로 암호화합니다. 이 시제품은 편지 내용을 AES-GCM으로 암호화하고 열쇠를 둘로 나눕니다. 링크에는 암호문과 한쪽 열쇠가, Cloudflare D1에는 다른 쪽 열쇠만 저장합니다. 서버에 원문이나 전체 열쇠는 보내지 않습니다.

한 사람에게 보내면 첫 열람 시 서버에 보관된 열쇠 조각을 없애 다른 기기에서의 새 열람을 막습니다. 단톡방 링크는 첫 사람이 연 순간부터 전원의 시간이 함께 흐릅니다. 공개 링크는 누구나 열 수 있습니다.

열람 중 확보된 해독 열쇠나 화면 저장, 서버 백업, 변조된 기기까지 없애는 절대 복구 불가는 보장되지 않습니다. 실험판에 민감한 내용을 넣지 마세요. 읽지 않은 편지의 서버 기록은 7일 후 열람 시 만료 처리됩니다.

일반적인 GitHub Pages 파일만으로는 기기 간 전역 소멸을 만들 수 없습니다. 외부 기록 서비스가 연결되지 않으면 보내기를 진행하지 않습니다.
